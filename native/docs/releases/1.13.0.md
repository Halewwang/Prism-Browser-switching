# Prism v1.13.0 公开测试版

版本为 1.13.0（构建 3），面向 macOS 15 或更新版本的 Apple Silicon 与 Intel Mac。

本次按 Pen 设计统一原生引导、历史、规则、设置和浏览器管理界面，改善分组、留白、文字层级和控件一致性。

- 统一按钮、输入框、下拉框和开关的视觉样式，明确主要与次要操作。
- 较长规则表单支持滚动，保存与取消保持可见；下拉框支持方向键、回车、空格和 Esc，并恢复键盘焦点。
- 修复历史筛选标签截断，改善浅色/深色次要文字对比度，保留安全网址与完整的来源、目标、结果及时间信息。
- 浏览器管理显示完整路径提示和明确的移除目标；设置操作行整行可点击。
- 补齐中文引导错误提示，规则保存失败时保留表单内容。

## 发布核验

384 项原生单元测试、81 项核心测试通过；此前 10 项相关 UI 交互用例分批通过。最终版本化自动复核中，中文引导和设置操作行两项通过；规则表单键盘用例因 XCTest 前台切换导致弹层关闭而失败，未计入通过数，Esc、空格、方向键及回车已在真实界面中直接复核通过。Universal Release 构建通过；安装包内所有 Mach-O 工件均包含 arm64 与 x86_64，Bundle 版本、严格签名、硬化运行时及 DMG 完整性已经复核。架构校验脚本改为逐架构检查，以兼容本机 lipo 工具。

本轮界面通过电脑控制工具直接截图核对。当前多显示器/屏幕共享环境下，XCTest 窗口截图 API 失败，因此自动图像亮度与明暗外观断言未执行；详情见 [界面审查报告](../interface-review-2026-09-29.md)。

## 安装与更新

下载 DMG，退出 Prism，将 Prism 拖入 Applications 替换旧版，再重新启动。现有设置和历史记录保留。此构建从 GitHub 检查更新并提示手动下载安装包。

沿用原生版公开测试发布方式，使用 ad hoc 签名，尚未经过 Developer ID 签名和 Apple 公证；macOS 可能显示安全提示。
