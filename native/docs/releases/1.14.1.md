# 1.14.1 / Build 2 — App 内更新公开测试版

本版本作为原生公开测试版发布。App 内下载与校验已验证，完整自动重启的实机验收仍未通过；安装重启为测试能力，可能需要手动安装。

更新检查有新版时打开原生更新窗口。用户可在 App 内下载、查看进度、取消和重试；更新签名、大小、SHA-256、应用身份、版本和系统要求全部通过后，才显示“安装并重启”。下载完成不会自动替换应用。

确认安装时，独立助手重新验证可信 DMG，准备同目录新包。主应用先刷新链接持久化；处理中、待处理、未保存或迟到的链接会阻止退出。只有最终 commit 与精确原进程退出同时成立，助手才备份并替换应用，通过系统 LaunchServices 重启。失败恢复旧包，恢复失败保留备份。

公开测试版继续使用 ad hoc 签名和硬化运行时，无 Sparkle。Ed25519 更新签名用于验证发布内容，不等同于 Developer ID 或 Apple 公证。保留 quarantine 和系统安全检查；已兼容通过代码身份验证的系统转位。保留下载隔离标记的未公证新包在本机仍未完成启动，助手已正确回滚；此时需要手动安装。本次发布继续保留下载隔离标记，不自动绕过该标记触发的系统安全检查。

1.14.0 及更早版本需要手动安装一次本版本才能获得新更新能力。规则和历史保存在应用包之外。

发布工件位于 `native/build/release/1.14.1-2/`，包括 Universal DMG、SHA256SUMS.txt、update-manifest.json、update-manifest.sig。四个工件作为同一版本资产发布。不得单独覆盖旧版本资产。

验证记录见 [完整更新交付记录](../../../docs/in-app-update-delivery-2026-09-30.md)。来源应用、浏览器 Profile、Intel 实机及其他 macOS 的先前验收缺口保持不变，不因本轮更新测试而宣称完成。
