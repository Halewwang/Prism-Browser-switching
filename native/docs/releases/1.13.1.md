# Prism v1.13.1 公开测试版

版本为 1.13.1（构建 4），适用于 macOS 15 或更新版本的 Apple Silicon 与 Intel Mac。

v1.13.0 在启动时被 macOS 的动态库校验阻止：虽然公开测试版实际使用 GitHub 检查更新，主程序仍链接了 Sparkle，ad hoc 签名的主程序与嵌入框架无法通过运行时库校验。v1.13.1 使用独立公开测试构建目标，不链接或打包 Sparkle，继续通过 GitHub Releases 检查更新。Developer ID 正式版构建仍保留 Sparkle。

## 发布核验

384 项原生单元测试通过（0 失败、0 跳过）。Universal Release 构建包含 arm64 和 x86_64。公开测试包保留硬化运行时，经严格代码签名检查、动态依赖检查、DMG 完整性校验；从 DMG 和 `/Applications` 安装位置实际启动后均保持运行。校验脚本还确认旧的 v1.13.0 包会因 Sparkle 动态依赖而被拒绝。

安装包：`Prism-1.13.1-universal-test.dmg`

SHA-256：`cb2d19839f974996c5627ab5e4e6637dfac7941444cdbf9dce3a86c6afcf7885`

## 安装与更新

下载 DMG，退出 Prism，将 Prism 拖入 Applications 替换旧版，再重新启动。设置与历史数据保留在应用程序包外。此版本沿用公开测试发布方式，使用 ad hoc 签名，尚未经过 Developer ID 签名和 Apple 公证。
