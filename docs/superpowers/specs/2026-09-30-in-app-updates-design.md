# App 内完整更新设计

用户选择：App 内下载、校验，确认后替换应用并重启。当前公测继续使用 ad hoc 签名和硬化运行时，不重新链接 Sparkle，不关闭 Gatekeeper 或移除 quarantine。

## 用户流程

检查更新后展示新版本、发布说明和“下载更新”。独立更新窗口显示下载进度，可取消或重试。下载完成后显示“安装并重启”；仅用户点击后退出。正在处理链接时暂缓安装，提示先完成当前链接。用户没有应用目录写权限、应用位于只读磁盘映像或目标不符合当前应用时，保留下载包并给出手动安装入口。

## 可信下载与准备

只接受既有仓库的 HTTPS 精确版本资产，解析同一 release 的 SHA256SUMS.txt、资产字节大小与可选 API digest。限制文件大小，校验实际长度及 SHA-256。拒绝缺失校验、异常文件名、路径穿越、重复校验条目、错误 digest 和非 HTTPS 重定向。完整性由 GitHub HTTPS 发布信息和校验文件建立，不能称为 Developer ID 或独立开发者签名认证。

DMG 只读挂载到独立临时目录，只复制根目录 Prism.app，随后卸载。验证候选包 bundle ID、预期版本、最低系统版本、可执行文件和完整代码签名；拒绝符号链接逃逸和非法包。保留文件扩展属性与 macOS 安全检查。所有下载、挂载、准备文件在独立 workspace，取消和失败清理，安装前保留可重试包。

## 替换与恢复

内嵌独立原生安装助手。主应用传递受保护的计划文件，助手验证源、目标与父 PID，完成准备握手后主应用退出。助手等待父进程退出，不主动杀死用户进程；超时不替换。先在目标同目录准备完整新包，再备份旧包并替换。复制、校验、替换任一步失败，旧应用保留或恢复；新应用无法通过 LaunchServices 启动时恢复并尝试打开旧应用。备份至少保留到启动成功，结果写入独立 receipt。启动成功不等于所有业务功能健康。

目标必须是当前运行的 Prism.app，可写的正常 app bundle 与父目录；拒绝根目录、符号链接、只读 DMG、身份不符、目标已有其他更新或候选不是更新版本。助手及主包均按架构和签名流程打包，不读取或修改用户规则、历史、默认浏览器及账户配置。

## 验证

对可信 release 元数据、哈希/大小、失败与取消、重复操作、安装确认、非法目标、父进程等待、替换失败回滚和重启失败写行为测试。真实文件操作仅用临时合成目录。实际下载/挂载/签名使用公开 DMG，在隔离测试应用及临时安装目录进行；不替换 /Applications/Prism.app。原生单测、UI 验证、Universal 包及隔离启动检查必须通过。

现有 1.14.0 不含新安装助手，用户需手动安装一次包含本能力的新版本，之后才能使用 App 内完整更新。没有 Apple 公证时系统仍可能要求用户手动允许打开；这不通过绕过安全检查解决。
